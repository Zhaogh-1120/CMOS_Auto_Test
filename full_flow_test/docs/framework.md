# Python + Ginkgo 自动化测试框架图

```text
┌─────────────────────────────┐
│ 终端 / 测试命令             │
│ python main.py ...          │
│ python -m tests....         │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 测试用例层 (tests)          │
│ - 单次写读验证              │
│ - 向量写读验证              │
│ - 边界值验证                │
│ - 随机回归验证              │
│ - 重复稳定性验证            │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 协议层 (protocol/chip_spi)  │
│ - write_reg()               │
│ - read_reg_raw()            │
│ - decode_read_value()       │
│ - write_then_read()         │
│ - sweep_reg()               │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 驱动层 (driver/control_spi) │
│ ctypes 调用 Ginkgo_Driver   │
│ - Scan/Open/Init SPI        │
│ - WriteBytes                │
│ - WriteReadBytes            │
└──────────────┬──────────────┘
               │ USB
               ▼
┌─────────────────────────────┐
│ Ginkgo SPI 适配器           │
└──────────────┬──────────────┘
               │ SPI
               ▼
┌─────────────────────────────┐
│ 被测芯片                    │
│ SDI: 写入命令/地址/数据     │
│ SDO: 回读寄存器数据         │
└─────────────────────────────┘
```

## 当前已验证协议

- 写地址帧：`00 [addr]`
- 写数据帧：`40 [data]`
- 读帧：`80 [addr]`
- 回读解码：默认 `raw_rx[1]`
- 当前稳定模式：
  - `control_mode=0`
  - `cpol=0`
  - `cpha=0`
  - `clock=500000`

## 数据闭环

1. Python 发送写帧到 Ginkgo
2. Ginkgo 经 SPI 将数据写入芯片
3. Python 再发送读帧
4. 芯片从 SDO 返回回读数据
5. DLL 将收到的字节回传给 Python
6. Python 解码 `raw_rx[1]`
7. Python 比较“写入值”和“回读值”
8. 终端显示 `PASS` / `FAIL`
